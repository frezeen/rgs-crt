# Changelog

## 2026-11-05

- **Taito Type X2: certified 100% on 15 kHz CRT (25/25 titles, owner verde).** Every dump in `/userdata/roms/typex2/` was launched one by one on the glass. Three titles carry their own canvas: Chase H.Q. 2 and Wacky Races declare an 800x600 fullscreen 4:3 device (payload note / dump `wr.ini`) and run nested 800x600 with the 640x480 output raster so Wine scales nothing and the picture is not distorted; Cyber Diver (Source engine, picture laid out for the window's client size) pins the payload's declared 1360x768 gamescope canvas. The rest run on the class 1280x720 → 864x486 stretch canvas, plus the already-certified exceptions (Elevator Action Death Parade portrait direct with its own cabinet strips, KOF MIRA direct 640x480, KOF XII DirectShow WMV shim).

- **Taito Type X2: The King of Fighters XII certified on 15 kHz CRT.** The game's DirectShow intro (`media/video/opening.wmv`) and title loop (`title_background.wmv`) now play smoothly instead of hanging on a black screen. Under Wine, the game looks for the video decoder filter by name (`"WMVideo Decoder DMO"`) to splice its `SampleGrabber` onto its output pin; Wine's `FindFilterByName` returns the file reader instead, disconnecting the grabber. Setting `WAL_DSHOW_FIND_FILTER: "1"` in the authored userprofile intercepts `FindFilterByName` and returns the true decoder filter, while `WAL_D3D9_FULLSCREEN_SIZE: 1280x720` matches gamescope's 16:9 canvas so `CreateDevice` succeeds directly without falling back to a misaligned window. Tested with owner verde on the glass.

## 2026-11-04

- **Profile picker: two pictures instead of two buttons.** The launch-time profile chooser now shows the arcade cabinet for the 15 kHz CRT profile and a flat-panel TV for the LCD one, each with its name and description ("4:3 CRT 15 kHz", "modern LCD/TV 16:9 high definition"), and a large up-arrow under the selected panel as the selection indicator. The artwork is transparent and composites on the picker's black raster, so the tube shows the cabinet and the TV and nothing else; the unselected picture steps back, dimmed.
- **The integrity check no longer flags a stray Python cache.** A `__pycache__` directory left by a development run made it report a difference that was not one; it now ignores it, exactly as the deploy copy already did.
- **Taito Type X2: King of Fighters Maximum Impact Regulation A certified on 15 kHz CRT.** The title runs direct on the 640x480i raster (`gamescope = 0`), which is what lets the runner's patched ddraw put its CRI Sofdec intro — a DirectDraw YUY2 overlay — on the real screen instead of on a nested swapchain. Disabling Mesa's threaded OpenGL worker (`mesa_glthread: "false"`), forcing DRI2 2D blits (`LIBGL_DRI3_DISABLE: "1"`) and ignoring vblank desync (`vblank_mode: "0"`) eliminate both the Wine gl-thread TLS segfault and the GPU driver command-stream rejection on 640x480i: the intro movie plays smoothly through without crashing and the game enters gameplay normally. Tested with owner verde on the glass.

## 2026-11-03

- **Taito Type X2: Elevator Action Death Parade brings its own cabinet to the 4:3 tube.** The portrait arcade picture now keeps its 9:16 shape at full height, and the space at its sides is filled with the game's **own** arcade cabinet — doors, walls and warning stickers — recomposed for the 4:3 tube. The stock doors pack is off for this title: it is drawn for 16:9 screens and could only be stretched here, which squashed the picture with it. The animated doors are the declared price of the correct picture.
- **The cabinet never outlives its game.** A portrait cabinet's side strips could stay on screen after its game closed — sitting over the profile chooser, or appearing over a different Type X2 title. They now exist only while their own game's window is on screen, and the chooser hands the tube back clean instead of leaving its last picture behind.
- **Sega RingEdge: certified 100% on 15 kHz CRT.** The full Sega RingEdge and RingEdge 2 arcade roster is now certified on the tube. High-definition 16:9 widescreen canvas titles scale edge-to-edge onto the 4:3 glass without letterboxing (**Sega RingEdge: Initial D Arcade Stage 6/7/8**, **Sega RingEdge: Guilty Gear Xrd -SIGN-**, **Sega RingEdge: Guilty Gear Xrd Revelator / Rev2**, **Sega RingEdge: Under Night In-Birth Exe:Late**, **Sega RingEdge: Blade Strangers**, etc.); native 4:3 titles with baked 16:9 pillar bezels (**Sega RingEdge: Guilty Gear XX Accent Core Plus R**, **Sega RingEdge: Melty Blood Actress Again Current Code RE2**) crop directly to authentic 4:3 full-bleed on CRT via D3D9 source rect in Windows Arcade Loader userprofiles with zero GPU overhead.
- **RGS 43.76 system compatibility.** Layer certified and fully aligned against live RGS 43.76 system update, ensuring display services, launch hooks, and update notifications operate reliably.
- **EmulationStation on-screen update notifications for RGS base system and CRT layer.** Enhanced update checks to distinguish and notify users via on-screen message box when a newer base RGS system update or combined update is available, with background throttling to prevent duplicate prompts during a session.
- **Session cleanup and lazy overlay unmount.** Enhanced launch and deploy scripts to automatically clean up squashfs overlay and Wine mount points upon game termination, preventing device-busy collisions.

## 2026-10-31

- **ArcadePC: Sega Rally 2 25th Anniversary [4-3] runs on the solo 15 kHz CRT.** Its D3D layer dereferences NULL when its device is created with the LCD disabled (page fault in MGameD3D.dll); hosting the title under a 4:3 gamescope canvas (1280x960 → 640x480) with authored dgVoodoo (FullScreenMode=true, ScalingMode=stretched) gives it its own output so the disabled CRT never reaches the game — full-frame 4:3 picture, no letterbox.
- **ArcadePC: Senninha GP runs on the solo 15 kHz CRT.** The stock wine-tkg runner ships a 4 KB ddraw.dll stub with no exports, so DirectDrawCreateEx is unimplemented and the title dies at startup; running it under the wine-9.17 runner (full 32-bit ddraw) with the same 4:3 gamescope canvas restores the picture with the LCD off.
- **Cleaner teardown on game launch.** Orphaned Windows processes and stale wine mount points are now cleared at gameStart, preventing locked loop devices and hangs when re-launching a title.
