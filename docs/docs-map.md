# The manual map

This folder is the user manual for the RGS 15 kHz CRT layer. Every page
is written in effects language — what you see, press and get — so you
can use the layer without knowing how it works inside.

| Page | Read it when |
| --- | --- |
| [Setups & screens](setups.md) | You want to know what the tube and the LCD do — and why the LCD goes dark during games. |
| [Profiles](profiles.md) | You want to understand the choice you're given. |
| [Writing & maintaining profiles](writing-profiles.md) | You want to build your own, or tune the shipped ones — every command, with examples. |
| [Install & updates](install-and-updates.md) | You want to know exactly what the install touches, and what happens after an RGS update. |
| [Compatibility map](emulators-status.md) | You want to know if your system works — with the measured numbers. |
| [Stock RGS notes](rgs-stock-issues.md) | You hit something that looks like RGS's own behavior, not ours. |

The root [README](../README.md) is the single project manifest: what the
layer is, how to install it, and where to report a problem. The
[changelog](../changelog.md) carries the user-facing history of recent
releases.
